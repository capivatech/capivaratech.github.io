# capivatec.github.io

Site da **CapivaTech**: coletivo sem fins lucrativos de ex-estudantes de Engenharia Física da UNILA.
Matemática, física, automação e programação para resolver problemas reais.

Publicação: crie o repositório `capivatec.github.io` na organização `capivatec`, envie estes arquivos e ative o GitHub Pages (branch `main`, pasta raiz). O site fica em https://capivatec.github.io/
